# Финальный отчёт MoMedA_EnData

## Маршрутизатор

| Модель | Тест | Точность | По источникам |
|---|---|---|---|
| med-router-en-3b (v1) | 846 | 72.7% | ddxplus 97 · hcm 93 · mtsamples 73 · medmcqa 66 |
| med-router-en-v2-3b | 876 | **76.6%** | ddxplus 96 · hcm 96 · medmcqa 71 · mtsamples 71 |

v1 обучен до расширения DDX-маппинга: онко-/гастро-/невро-жалобы DDX
относил к Терапевту. v2 — расширенный маппинг (7 классов), датасет
перегенерирован. Обучение: 2 эпохи, ~2.5 ч, train/eval loss ≈ 0.04.

## Агенты-специалисты

Суммарно 113.7k примеров, 14 полных файнтюнов (~9.7 ч GPU). Детали —
`FINAL_METRICS.md`. Метрики сняты до унификации формата; после неё 7
HCM-тяжёлых агентов переобучены, индивидуально не переоценивались — их
сквозной эффект в e2e ниже.

## Мастер med-chief-3b

24k пар (DDXPlus 13.5k + MedMCQA 8.1k + USMLE 2.4k), 1 эпоха,
train 0.556 / eval 0.355. Шаг синтеза в конвейере 3–6 с.

## Переводчики (выбор по тесту 175 пар)

Вход RU→EN: MiLMMT-46-1B (резидентно, ~1 с) → NLLB-600M → Qwen.
Выход EN→RU: base Qwen — единственный, кто сохраняет структуру и термины.

Состав v2: роутер v2 + унифицированные агенты + мастер. Провал v1 —

Гастро 48% (взаимные).

## Инженерные выводы

- Инференс только на чистом transformers: unsloth глобально патчит классы,
  при 3+ экземплярах повторные загрузки падают (illegal memory access).
- Переводчик и агент не пересекаются в VRAM: роутер+мастер+агент+
  переводчик = 24.8 ГБ > 23.5 — в конвейере принудительные выгрузки.
- Обучение при max_len 2048 — batch 1×accum 16: батч из двух длинных
  примеров ловит OOM на пике логитов (~1.2 ГБ).
- Метрики снимать только по сохранённым сырым ответам: дрейф маркеров
  («Ответ:»↔«Answer:», русские↔английские заголовки) ломает регулярки,
  сырые ответы позволяют пересчитывать без GPU.
